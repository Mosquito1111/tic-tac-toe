# Tic-Tac-Toe (C)

> 基于控制台的经典井字棋游戏，玩家（`x`）对战电脑（`o`）。用纯 C 语言编写，无需任何第三方库。

---

## 项目简介

一个运行在命令行终端的**井字棋（Tic-Tac-Toe）**：你执 `x`，电脑执 `o`。
开局可以选择谁先走，输入 `1~9` 对应棋盘上的位置落子，率先连成三子（横、竖、斜任意一条线）者获胜，棋盘填满无人获胜则为平局。游戏支持无限重开一局。

项目结构非常轻量，目前全部逻辑集中在单个 `main.c` 中，由 4 个职责清晰的函数协作完成：

| 函数 | 作用 |
|------|------|
| `move()` | 读取玩家输入，校验合法性（数字范围 / 防呆输入 / 位置是否被占）后落子 |
| `spawn()` | 电脑走子：收集所有空位，再随机选一个落子（纯随机） |
| `is_gameover()` | 判定胜负 / 平局，返回 `1`（有人赢）/ `2`（平局）/ `0`（继续） |
| `draw()` | 把当前棋盘状态渲染到终端 |

## 编译与运行

### 环境要求
- 任意支持 C99 的编译器（本项目使用 **MinGW / gcc**，Dev-C++ 自带）
- 一个终端 / 命令行窗口

### Linux / macOS
```bash
gcc main.c -o tictactoe
./tictactoe
```

### Windows（MinGW）
```bash
gcc main.c -o tictactoe.exe
tictactoe.exe
```

> 也可以在 Dev-C++ 中直接打开 `main.c` 按 F11 编译运行。

## 玩法说明

启动后，控制台会显示一张带编号的 3×3 棋盘：

```
+---+---+---+
| 1 | 2 | 3 |
+---+---+---+
| 4 | 5 | 6 |
+---+---+---+
| 7 | 8 | 9 |
+---+---+---+
```

- **选择先手**：输入 `y`（玩家先走）/ `n`（电脑先走）/ `q`（退出游戏）。
- **落子**：输入 `1~9` 对应格子编号，非法输入（字母、越界、已占位）会被拦截并提示重新输入。
- **胜负**：横、竖、斜任意连成三子即获胜；棋盘填满无人获胜则平局。
- **再来一局**：一局结束后输入 `y` 重开，输入其它任意键退出。
